# BTC 매매 연습

비트코인 과거 차트(바이낸스 BTC/USDT)로 현물·선물 매매를 연습하고, 타점을 평가받는 웹앱입니다.

- 코인: BTC / ETH / SOL / XRP / BNB / DOGE
- 봉: 15분 / 30분 / 1시간 / 4시간 / 1일
- 지표: 이동평균선(20·60·120), 거래량, RSI(14), 볼린저밴드, MACD
- 리플레이 방식: 과거 시점부터 한 봉씩 진행하며 매수·매도(롱·숏) 연습
- 주문: 시장가 · 지정가, 손절·익절 예약, 리스크 기준 수량(손절 시 자산의 0.5·1·2%만 잃게)
- 매매 일지: 진입 근거 태그·메모, 근거별 승률
- 차트에 수평선·추세선·피보나치 되돌림 그리기, 가격 알림(닿으면 자동재생 멈춤)
- 상위 봉 미니 차트 (15분·30분→4시간, 1시간·4시간→1일, 1일→1주)
- 복기: 매매 시점으로 차트 이동, 보유 중 최고·최저 대비 실제 청산 비교
- 같은 구간 다시 도전과 지난 도전 비교
- 선물 펀딩비 (8시간마다 0.01%, 롱 지급)
- 타점 평가: 체결 시점 지표 분석 + 이후 가격 흐름으로 사후 평가 + 결과 리포트
- 블라인드 모드: 날짜·가격대를 숨기고 연습, 리포트에서 공개
- 자동 저장(이어하기)과 판별 성적 기록(내 기록), 기록 백업 파일 저장·불러오기
